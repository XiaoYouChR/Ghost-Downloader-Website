## Bilibili

### 登录与画质

未登录时 Bilibili 返回的最高画质为 480P。登录后可获取更高画质，具体取决于账号的会员状态：

| 账号状态 | 最高可用画质 |
|---|---|
| 未登录 | 480P |
| 已登录（普通用户） | 1080P |
| 大会员 | 1080P60 / 4K / HDR / 杜比视界 |

登录方式在设置 → Bilibili 下载 → **账号登录** 中配置，有两种方式：

- **扫码登录**：点击后显示二维码，使用哔哩哔哩手机客户端扫描并确认。二维码有效期约 180 秒，失效后点击「刷新二维码」重新生成。
- **导入 Cookie**：手动粘贴从浏览器导出的完整 Cookie 字符串。留空并保存可清除当前 Cookie。

如果安装了浏览器扩展，通过扩展发起的 Bilibili 下载会自动携带浏览器的登录状态，无需在应用内额外配置。

### 画质设置

设置 → Bilibili 下载 中的画质相关选项：

- **默认画质**：可选 240P 到杜比视界共 11 档。
- **画质不可用时**：当选定画质不可用时，选择最高画质或最低画质作为替代。
- **HDR**：请求 HDR 视频流（需要大会员）。
- **杜比全景声/视界**：请求杜比全景声和杜比视界（需要大会员）。

### 下载模式

任务草稿卡片上的下拉框可以切换下载模式：

- **视频**：下载视频流和音频流，合并为 `.mp4`
- **音频**：仅下载音频流，保存为 `.m4a`
- **封面**：下载视频封面图片

### 分P与字幕

多分P视频的链接粘贴后，可以通过「选择分P」按钮选择要下载哪些分P。也可以在链接的 `p` 参数中直接指定，支持逗号分隔和范围（如 `?p=1,3-5`）。

如果视频有字幕（包括 AI 自动生成的字幕），可以通过「选择字幕」按钮勾选要下载的语言。字幕会被转换为 `.srt` 格式保存。

## YouTube

### Cookie 与受限内容

大部分 YouTube 公开视频不需要登录即可下载。以下情况需要提供 Cookie：

- 年龄限制视频
- 会员专属视频
- 私密视频（需要已授权账号）
- YouTube 要求人机验证时

Cookie 的获取有两种方式：

1. **浏览器扩展自动导入**（推荐）：安装浏览器扩展后，通过扩展发起的 YouTube 下载会自动携带浏览器的登录 Cookie。如果 Cookie 中包含登录凭据（`LOGIN_INFO`、`SAPISID` 等），应用会自动保存以供后续使用。
2. **手动导入**：设置 → YouTube 下载 → **YouTube Cookie** → 导入。在浏览器中打开 YouTube 并登录，按 F12 打开开发者工具，在 Network 标签中找到任意请求，复制 Cookie 请求头的值并粘贴。

### 运行时

YouTube 下载依赖 yt-dlp 和 QuickJS 两个运行时组件，在设置 → YouTube 下载中一键安装。Android 端的 QuickJS 已内置，只需安装 yt-dlp。

### 地区限制

部分视频有地区限制。如果遇到「该视频在您所在地区不可用」错误，需要配置代理。

## GitHub Releases

GitHub Releases 的下载文件在中国大陆访问速度通常很慢。Ghost Downloader 内置了 GitHub 加速功能，自动将 GitHub 文件链接改写为反向代理站下载。

加速对以下域名和路径生效：

- `github.com/*/releases/download/*`
- `github.com/*/archive/*`
- `github.com/*/raw/*`
- `raw.githubusercontent.com`、`objects.githubusercontent.com` 等多个 GitHub 子域名

### 配置

设置 → GitHub 加速：

- **启用 GitHub 加速**：开关，默认开启。
- **代理站**：可从预置的代理站中选择（gh-proxy.com、gh-proxy.org、gh.ddlc.top、ghfast.top），也可以填写自定义代理站地址。点击刷新按钮可测试各代理站的响应延迟。

### 已知限制

- 加速仅对文件下载链接生效，不影响 GitHub API 或网页访问。
- 代理站的可用性和速度可能随时变化，建议定期刷新延迟测试。
- 如果全局已配置代理且代理可以直连 GitHub，可以关闭此功能。

## HuggingFace

### 镜像加速

HuggingFace 的模型和数据集仓库在中国大陆直接访问速度较慢。Ghost Downloader 内置镜像加速，将 HuggingFace 链接自动改写为镜像站。

默认镜像站为 `hf-mirror.com`，也可以在设置 → HuggingFace → **镜像站** 中切换为自定义镜像站。

### 仓库下载

粘贴 HuggingFace 仓库链接（如 `https://huggingface.co/org/model`）时，应用会列出仓库中所有文件及大小，可以选择需要下载的文件。粘贴单文件链接（包含 `/resolve/` 或 `/blob/` 路径的）则直接下载该文件。

支持的仓库类型：模型（models）、数据集（datasets）、Spaces。

### Access Token

部分模型需要授权才能下载（如 Llama、Mistral 等受限模型）。在设置 → HuggingFace → **Access Token** 中填写从 [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) 获取的 Token。

未配置 Token 时访问受限仓库会收到「该仓库需要授权，请在设置中配置 HuggingFace Access Token」的错误提示。

### 已知限制

- 镜像站的同步可能有延迟，最新上传的文件可能暂时无法通过镜像下载。
- 如果全局已配置代理且可以直连 HuggingFace，可以将镜像站设为空或关闭加速。
