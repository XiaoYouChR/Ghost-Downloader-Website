Ghost Downloader 的所有持久化数据（配置、任务记录、日志）保存在同一个目录下，称为**数据目录**。

## 数据目录位置

数据目录有两种模式。应用 → 数据存储模式 可以查看和切换当前模式。

### 用户模式（默认）

<Tabs groupId="os">
<Tab value="Windows">

```
C:\Users\<用户名>\AppData\Local\GhostDownloader
```

</Tab>
<Tab value="macOS">

```
~/Library/Application Support/GhostDownloader
```

</Tab>
<Tab value="Linux">

```
~/.local/share/GhostDownloader
```

</Tab>
<Tab value="Android">

应用内部存储，路径由系统分配，不可直接访问。

</Tab>
</Tabs>

### Portable 模式

数据目录位于可执行文件旁边的 `GhostDownloader/` 文件夹。适用于 U 盘携带或不想在系统目录留数据的场景。

切换模式时，数据会被复制到新位置，程序随后退出，需要手动重新打开。原数据目录不会自动删除（Portable 切用户模式时原目录被重命名为 `.bak`）。

## 目录结构

<Files>
  <Folder name="GhostDownloader" defaultOpen>
    <File name="UserConfig.json" />
    <File name="GhostDownloader.log" />
    <File name="GhostDownloader.log.1" />
    <File name="tasks.jsonl" />
    <Folder name="browser_extension" />
    <Folder name="FFmpeg" />
    <Folder name="YtDlp" />
  </Folder>
</Files>

| 文件 | 内容 |
|---|---|
| `UserConfig.json` | 所有设置项。JSON 格式，可手工编辑（关闭程序后再改）。 |
| `GhostDownloader.log` | 当前运行日志。单个文件最大 512 KB，超限后轮转，保留 5 个历史文件（`.log.1` 到 `.log.5`）。 |
| `tasks.jsonl` | 任务记录，每行一条 JSON。任务列表中看到的所有任务来自这个文件。 |
| `browser_extension/` | 一键安装时自动解包的浏览器扩展文件。 |
| `FFmpeg/`、`YtDlp/` | 功能包下载的运行时 Binary Runtime 存放位置。 |

## 提交 Issue 时附带日志

在 [反馈页面](/docs/dev/contributing/overview) 提交 Issue 时附带日志可以大幅减少排查时间。

日志文件可以通过两种方式打开：

- 设置 → 关于 → 提供反馈 → 查看日志，会直接在文件管理器中定位到 `GhostDownloader.log`。
- 手动进入上述数据目录，找到 `GhostDownloader.log`。

<Callout type="warn">
日志可能包含你的下载链接和文件名。提交前检查一遍，如有隐私内容请删除对应行后再附上。
</Callout>

如果问题发生在启动阶段（窗口根本没出现），当前日志可能是空的，尝试查看 `.log.1`（上一次运行的日志）。
