---
title: Aria2 RPC 兼容
description: 让 LinkSwift 等支持 Aria2 RPC 的工具把下载任务推送到 Ghost Downloader。
---

Ghost Downloader 内置了一个兼容 Aria2 JSON-RPC 的本地服务端，监听在 `127.0.0.1`。任何能向 Aria2 发送 `aria2.addUri` 的工具都可以把任务推送到 Ghost Downloader，不需要安装真正的 Aria2。

目前支持的 RPC 方法：

| 方法 | 说明 |
|---|---|
| `aria2.addUri` | 创建任务。支持 `out`（文件名）、`dir`（保存路径）、`header`、`user-agent`、`referer` 选项 |
| `aria2.getVersion` | 返回 Ghost Downloader 版本号 |

其余 Aria2 方法（`aria2.tellStatus`、`aria2.remove` 等）未实现，调用会返回 `Method not found`。

## 搭配 LinkSwift 使用

[LinkSwift](https://github.com/hmjz100/LinkSwift) 是一个油猴脚本，能在网页上提取网盘直链并通过 Aria2 RPC 推送下载。支持百度网盘、阿里云盘、移动云盘、天翼云盘、迅雷云盘、光鸭云盘、夸克网盘、UC网盘、123云盘。

配合 Ghost Downloader，流程为：LinkSwift 在浏览器中获取直链 → 通过 RPC 发送给 Ghost Downloader → Ghost Downloader 创建任务并下载。

<Steps>
<Step>

### Ghost Downloader 端

打开 **设置 → Aria2 RPC 兼容**，开启 **启用 Aria2 RPC 兼容**。

记住 **监听端口**（默认 `16800`）。如果设置了 **令牌**，把它复制下来——LinkSwift 那边要填。

</Step>
<Step>

### LinkSwift 端

在 LinkSwift 的设置中，将 RPC 地址设为：

```
http://127.0.0.1:16800/jsonrpc
```

如果 Ghost Downloader 端设置了令牌，在 LinkSwift 的 Token 栏填入 `token:<你的令牌>`（与 Aria2 的 `--rpc-secret` 格式相同）。

</Step>
<Step>

### 验证

在支持的网盘页面上点击 LinkSwift 的下载按钮。如果 Ghost Downloader 正常收到任务，配置完成。

如果任务没有出现，检查端口号和令牌是否一致，以及 Ghost Downloader 是否正在运行。

</Step>
</Steps>

## 模拟浏览器指纹

部分网盘的直链对 TLS 指纹有校验。如果下载失败或速度异常，在 **设置 → Aria2 RPC 兼容 → 模拟浏览器指纹** 中开启此选项。开启后，通过 RPC 接收的任务会附加浏览器 TLS 指纹与请求头。

<Callout type="warn">
模拟浏览器指纹需要运行时支持。如果运行时未安装，任务可能解析失败。
</Callout>

## 其他兼容工具

任何支持 Aria2 RPC 的工具都可以用相同方式接入，只要把 RPC 地址指向 `http://127.0.0.1:<端口>/jsonrpc` 并正确填写令牌。常见的场景包括浏览器扩展（如 Aria2 Explorer）和命令行脚本。

## 已知限制

- 仅监听 `127.0.0.1`，不接受来自其他设备的请求。
- 仅支持 `aria2.addUri` 和 `aria2.getVersion`，不支持查询任务状态、暂停、删除等操作。
- 不支持 WebSocket，仅接受 HTTP POST。
- 如果 **设置 → 浏览器扩展 → 接管下载时进入草稿模式** 开启，RPC 收到的任务也会进入任务草稿而不是直接开始下载。
