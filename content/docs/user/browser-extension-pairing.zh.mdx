## 安装扩展

三种安装方式，区别在于扩展的更新方式。

| 方式 | 适用浏览器 | 更新机制 |
|---|---|---|
| 一键安装（设置 → 浏览器扩展 → 安装到 Chromium 浏览器 → 一键安装） | Chrome、Brave 等 Chromium 系 | 随桌面端更新自动升级，无审核延迟 |
| 商店安装（设置 → 浏览器扩展 → 从商店安装扩展） | Chrome、Edge、Firefox | 需等商店审核后才能获得更新，可能滞后于桌面端 |
| 导出 CRX（设置 → 浏览器扩展 → 安装到 Chromium 浏览器 → 导出 CRX） | Chromium 系 | 手动导出 `.crx` 文件后自行安装，适用于无法使用一键安装的环境（如企业策略禁止开发者模式加载扩展） |

**一键安装**会将桌面端内嵌的扩展解包到本地目录，然后打开 `chrome://extensions` 页面并定位到该目录。你需要在浏览器中开启开发者模式，将扩展文件夹拖入浏览器窗口完成加载。因为扩展文件和桌面端打包在一起，每次桌面端更新后扩展会自动解包新版本并通知浏览器重新加载，无需手动操作。

**商店安装**提供 Chrome 商店、Edge 商店、Firefox 商店三个入口。商店版本的更新取决于各商店的审核周期。

## 配对流程

扩展安装完成后需要与桌面端配对，扩展才能向桌面端发送下载请求。

<Steps>

### 确认桌面端已启用浏览器扩展

设置 → 浏览器扩展 → 启用浏览器扩展 保持开启（默认已开启）。

### 在扩展中发起自动配对

打开扩展弹窗，进入设置页面，点击自动配对。桌面端会弹出「浏览器扩展配对请求」对话框，显示来源地址和扩展版本。点击允许配对。

扩展自动获得配对令牌并建立连接，弹窗顶部的连接状态指示器变为已连接。

</Steps>

如果自动配对不可用（例如桌面端未在前台、弹窗被拦截），改用手动方式：在设置 → 浏览器扩展 → 配对令牌处点击复制令牌，然后在扩展设置页面的配对令牌输入框中粘贴。

## 配对令牌

配对令牌是扩展连接桌面端的凭证。首次启用浏览器扩展时自动生成。

- **位置**：设置 → 浏览器扩展 → 配对令牌。
- **复制**：点击复制令牌按钮，令牌复制到剪贴板。
- **重新生成**：点击配对令牌卡片右侧的重新生成令牌按钮（旋转图标）。新令牌立即生效并自动复制到剪贴板，**所有已连接的扩展会立即断开**，需要在扩展中重新输入新令牌或再次自动配对。

什么时候该重新生成：

- 令牌泄露给不受信任的程序或用户。
- 更换了浏览器、清除了扩展数据后需要重新配对（旧令牌仍然有效，重新输入即可；如果记不住旧令牌，重新生成一个）。

## 服务端口

桌面端通过 WebSocket 在本机监听连接，扩展主动连接桌面端。

- 默认服务地址：`ws://127.0.0.1:14370`
- 端口可在设置 → 浏览器扩展 → 服务端口中修改，范围 1024–65535。修改后需要在扩展设置页面的本地服务地址中同步更新端口号。
- 如果默认端口被其他程序占用，桌面端启动时会在设置页面提示端口被占用，此时需要换一个空闲端口。

## ghostdownloader:// 协议唤醒

开启后，浏览器扩展可以通过 `ghostdownloader://` 协议链接启动桌面端。当扩展检测到桌面端未运行时，会尝试通过此协议唤醒桌面端，而不需要你手动打开。

该开关在设置 → 关联设置 → 允许浏览器扩展唤醒。macOS 上此选项不可用。
