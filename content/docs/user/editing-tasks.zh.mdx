---
title: 编辑任务
description: 修改 URL、请求头、代理、身份预设和文件选择。
---

右键任务卡片 →「编辑任务参数...」（任务尚未完成时可用）。显示的选项取决于任务的协议类型。

## 更换 URL

修改「下载链接」字段后点击「应用」，Ghost Downloader 会重新解析新 URL。

- 如果新 URL 的内容与原 URL 一致（文件大小和结构相同），已下载的进度可以复用。
- 如果不一致，且任务已有下载进度，会弹出确认对话框：「新链接与原链接的内容不一致，将清除已下载的 x 数据，是否继续？」。确认后已下载的数据会被删除，任务从头开始。
- 如果新 URL 解析失败，对话框顶部会显示「链接解析失败」错误，任务不会被修改。

## 编辑请求标头

两种编辑模式，通过工具栏切换：

- **表格视图**——每行一个标头，分为名称和值两列。
- **文本视图**——自由文本，每行一个 `名称: 值`，也可以直接粘贴 cURL 命令（只取第一条）。

<Callout type="warn">
当模拟身份（Client Profile）不是「不模拟（原样发送）」时，你手动设置的 `User-Agent` 和 `sec-ch-ua` 标头不会生效——它们会被 TLS 指纹对应的值覆盖。如果需要完全控制这两个标头，把模拟身份设为「不模拟（原样发送）」。
</Callout>

## 请求标头预设

如果你经常需要为不同站点设置不同的请求标头，可以在「设置 → 请求标头预设」中保存预设。每个预设包含一个名称和一组标头。新建任务时，对话框中的请求标头会以选中的预设为起点。

## 代理

Ghost Downloader 在「设置 → 代理」中提供三种模式：不使用代理、自动检测系统代理、使用自定义代理（socks4、socks5、socks5h、http、https）。

### 不同下载方式对代理协议的支持不同

| 下载方式 | 支持的代理协议 |
|---------|-------------|
| HTTP    | socks4, socks5, socks5h, http, https |
| M3U8    | socks4, socks5, socks5h, http, https |
| BT      | socks5 |
| FTP     | socks4, socks5 |

**如果你同时使用多种下载方式且需要代理，选 SOCKS5 是唯一不会踩坑的选择。**

## 身份预设

「设置 → 模拟身份」中可以按域名配置不同的 TLS 指纹和 User-Agent 组合。

全局默认的模拟身份在没有预设匹配时生效。每个站点预设包含：

- **匹配 Host**——输入域名后按回车添加，支持精确匹配（`pcs.baidu.com`）和通配符（`*.pcs.baidu.com` 匹配所有子域名）。至少添加一个 Host。
- **TLS 指纹**——选择要模拟的浏览器指纹，或者选「跟随全局默认」。
- **User-Agent**——留空则根据 TLS 指纹自动生成。

## 文件选择

种子、FTP 目录等多文件任务可以勾选要下载的文件。在任何任务状态下都能改。

- 取消勾选不会删除已下载的数据。重新勾选后从断点继续。
- 任务显示「已完成」后勾选新文件，任务会自动继续下载。
- 取消勾选的文件如果正在下载中，Ghost Downloader 会中断该文件的下载，其余文件不受影响。
