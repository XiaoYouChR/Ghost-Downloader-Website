只收录不容易一眼看懂的设置项。最大任务数、下载路径、限速等一看就懂的设置这里不重复解释。

所有设置保存在数据目录的 `UserConfig.json` 中，详见 [配置文件与日志位置](/docs/user/configuration-file)。

## 综合下载设置

<TypeTable
  type={{
    "预分配线程数 (Pre-allocated Threads)": {
      type: "number",
      default: "8",
      description: "每个任务启动时开启的分片数。范围 1 ~ 256。数值越大，单任务吞吐越高——前提是服务器允许。超过 64 时有被服务器反爬机制拦截的风险，表现为下载后文件损坏或校验不通过。如果你下载的文件来自 CDN 或大型云存储，保持 8 ~ 32 比较安全；如果是自己的服务器或没有并发限制的来源，可以调高。"
    },
    "自动提速 (Auto Boost)": {
      type: "boolean",
      default: "true",
      description: "运行时监测各分片效率，当检测到分片速度不均时自动增加分片数。关闭它的唯一理由是目标服务器对并发数非常敏感（比如始终返回 429），你想完全手动控制线程数。"
    },
    "最小再分配大小 (Minimum Redistribution Size)": {
      type: "number",
      default: "512 (KB)",
      description: "只有当某个分片的剩余工作量大于此值时，才会把它拆分给其他已完成的分片或新增分片。范围 64 ~ 102400 KB。调大：减少小文件上的频繁拆分开销。调小：让分片之间的负载更均匀，适合网速波动大的环境。"
    },
    "下载时验证 SSL 证书 (Verify SSL Certificates)": {
      type: "boolean",
      default: "false",
      description: "开启后会校验服务器证书链。默认关闭是因为部分企业代理和校园网会注入自签名证书导致下载失败。如果你在可信网络环境下希望防止中间人攻击，可以打开。修改后需要重启才能生效。"
    },
    "保留文件修改时间 (Preserve file modification time)": {
      type: "boolean",
      default: "false",
      description: "下载完成后把文件的修改时间设为服务器返回的 Last-Modified 值。适合需要按时间排序文件或做增量备份的场景。如果服务器不返回 Last-Modified，此选项无效。"
    },
    "同时删除已下载的文件 (Also delete downloaded files)": {
      type: "boolean",
      default: "false",
      description: "控制删除任务确认对话框中「同时删除已下载的文件」复选框的默认勾选状态。上一次删除任务时你选了什么，下次就默认选什么。设为 true 后每次删除任务都会默认勾选删除文件——误操作会丢文件，请谨慎。此项在界面中没有独立的设置入口，只在删除确认对话框中出现。"
    },
  }}
/>

## 模拟身份

<TypeTable
  type={{
    "客户端档案 clientProfile (Client Profile)": {
      type: "string",
      default: '"auto"',
      description: "决定下载请求使用的 TLS 指纹和 HTTP/2 参数。auto：根据链接来源自动匹配浏览器指纹。chrome / edge / firefox / safari / okhttp 等：锁定为该浏览器家族的最新版本指纹。raw：不模拟，原样发送——某些服务器依赖非标 TLS 行为时使用。当下载返回 403 且你确定链接有效时，切换 clientProfile 往往能解决问题。"
    },
  }}
/>

## 浏览器扩展

<TypeTable
  type={{
    "服务端口 (Service Port)": {
      type: "number",
      default: "14370",
      description: "浏览器扩展通过此端口与桌面端通信。范围 1024 ~ 65535。只有当 14370 被其他程序占用时才需要改，改完后需要在扩展侧同步填写新端口。"
    },
    "接管下载时进入草稿模式 (Enter draft mode when intercepting downloads)": {
      type: "boolean",
      default: "false",
      description: "开启后，浏览器扩展接管的下载不会立即开始，而是先创建任务草稿，弹出窗口让你修改文件名、保存路径或勾选可选文件。适合经常需要改名或选目录的用户。关闭时，接管的下载会按当前默认设置直接开始。"
    },
  }}
/>
