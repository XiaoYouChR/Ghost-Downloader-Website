## 模板展开

如果你要下载的链接有规律可循——连续编号的图片、多个格式的视频——可以用模板语法批量生成。

点击「添加任务」对话框中的「批量添加」按钮，打开「批量添加」对话框。在模板输入框中写入带占位符的 URL，下方会实时预览展开结果和链接数量。

## 模板语法

### 数字范围 `[start-end]`

```
http://example.com/img/[1-100].jpg
```

展开为 `img/1.jpg`、`img/2.jpg`、...、`img/100.jpg`，共 100 个链接。

### 补零 `[001-050]`

起始数字带前导零时，展开的数字会自动补零到相同宽度：

```
http://example.com/img/[001-050].jpg
```

展开为 `img/001.jpg`、`img/002.jpg`、...、`img/050.jpg`。

### 步长 `[start-end:step]`

```
http://example.com/page/[1-10:2].html
```

展开为 `page/1.html`、`page/3.html`、`page/5.html`、`page/7.html`、`page/9.html`。

### 字母范围 `[a-z]`

```
http://example.com/part_[a-f].zip
```

展开为 `part_a.zip` 到 `part_f.zip`。大写字母同理（`[A-F]`）。大小写不能混用。

### 枚举 `{val1,val2,val3}`

```
http://example.com/{mp4,mkv,avi}/video
```

展开为三个链接，分别包含 `mp4`、`mkv`、`avi`。

### 组合

一个模板中可以同时使用多个占位符，Ghost Downloader 会计算它们的笛卡尔积：

```
http://example.com/{en,zh}/chapter_[01-03].pdf
```

展开为 6 个链接：`en/chapter_01.pdf`、`en/chapter_02.pdf`、`en/chapter_03.pdf`、`zh/chapter_01.pdf`、`zh/chapter_02.pdf`、`zh/chapter_03.pdf`。

## 计划：全部完成后做什么

如果你有一批任务要下载，想在全部完成后自动执行某个操作（比如睡前挂机下载），可以使用**计划**功能。

在任务列表工具栏上点击「计划任务」按钮（时钟图标），打开「设置计划任务」对话框。对话框显示「所有任务完成后执行以下操作：」，可选择：

- **关机**
- **重启**
- **睡眠**
- **打开文件**——选择此项后需要指定文件路径。

设置后，「计划任务」按钮保持按下状态，表示计划已激活。再次点击该按钮可以取消计划。

当所有任务（包括排队等待的任务）全部完成后，Ghost Downloader 会执行你选择的操作。
