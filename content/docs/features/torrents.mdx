---
title: Download Torrents
description: BitTorrent and Magnet link downloads.
---

Add via magnet link (paste or intercept) or .torrent file (drag into window).

Magnet links need a few seconds to fetch the file list from the network.

**File selection:** pick which files to download. Can be changed anytime via **right-click → File Selection**.

**Seeding:** automatic after completion. Configure limits in **Settings → BitTorrent**.

**Proxy:** SOCKS5 only for download traffic (**Settings → Proxy**).

Android does not support BitTorrent.
