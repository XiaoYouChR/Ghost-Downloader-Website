<Callout type="warn" title="Not supported on Android">
The Android version does not include BitTorrent functionality.
</Callout>

## Add

- Magnet links — paste or capture from the browser
- .torrent files — drag into the window or click to import

Magnet links require fetching the file list first, which usually takes a few seconds to tens of seconds.

## File Selection

For multi-file torrents, you can select the files you need. You can also change this during download: **Right-click the task → File Selection**.

Unchecked files keep the already downloaded parts; re-checking continues from them.

## Seeding

Seeding starts automatically after download completes. **Settings → BitTorrent** lets you configure the share ratio limit and time limit. You can also stop manually at any time.

## Proxy

**Settings → Proxy** configures a SOCKS5 proxy. Only SOCKS5 applies to download traffic.

## Resume

After pausing or exiting and restarting, continue from the last position.
