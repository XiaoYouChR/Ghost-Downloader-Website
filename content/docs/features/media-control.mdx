---
title: Media Control Panel
description: Control playing media without switching tabs.
---

Click extension icon → Advanced → Media Control.

| Action | Description |
|---|---|
| Play/Pause | Toggle playback |
| Volume | Slider |
| Speed | Adjust playback speed |
| PiP | Picture-in-Picture |
| Screenshot | Save current frame |
| Loop | Toggle loop |
| Seek | Drag to jump |
