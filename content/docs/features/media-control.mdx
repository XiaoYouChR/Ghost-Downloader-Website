---
title: Media Control Panel
description: Control video or audio playing on the page without switching tabs.
---

Click the extension icon → Advanced → Media Control. You can control video/audio playing in the current tab.

| Action | Description |
|---|---|
| Play/Pause | Toggle playback state |
| Volume | Slider adjustment |
| Speed | Adjust playback rate |
| Picture-in-Picture | Pop out a floating playback window |
| Screenshot | Save the current frame as an image |
| Loop | Toggle loop playback |
| Progress | Drag to seek |

When a background tab plays a tutorial or music, you can pause, change speed, or take a screenshot without switching to it.
