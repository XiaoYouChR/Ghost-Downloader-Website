---
title: eD2k Download
description: Download files via ed2k:// links.
---

Ghost Downloader supports `ed2k://` protocol links.

## Prerequisites

The eD2k feature depends on an external runtime. Before first use, install the corresponding runtime in **Settings → General Download Settings**.

## URI Scheme Association

After registering the `ed2k://` protocol in **Settings → Association Settings**, clicking an eD2k link in a browser or other program automatically opens GD.

<Callout type="warn" title="Platform Limitations">
The Android version does not support eD2k (the feature is removed at build time). Association settings are only available on Windows and Linux.
</Callout>
