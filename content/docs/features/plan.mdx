---
title: Post-Completion Actions
description: Shut down, restart, or sleep after all downloads finish.
---

Click the clock icon in the toolbar.

| Action | Effect |
|---|---|
| Shutdown | Power off |
| Restart | Reboot |
| Sleep | Hibernate |
| Open File | Open a specified file |

Triggers after all running/queued tasks complete. Click the clock icon again to cancel.
