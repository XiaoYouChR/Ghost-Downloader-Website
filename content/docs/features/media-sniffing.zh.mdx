## 下载按钮

鼠标悬停在正在播放的视频上时，会出现下载按钮。点击后扩展自动识别视频资源并发送到桌面端。

按钮可以拖拽移位。点 `×` 关闭（刷新恢复）。扩展设置中可全局关闭此按钮。

## 资源列表

点击扩展图标 → 资源。这里显示当前页面产生的所有媒体网络请求。

当页面有多种画质时，各画质会作为独立条目出现。选中后点下载发送到桌面端。

对于视频和音频分开传输的站点（常见于高清视频），选中一条视频和一条音频后可以使用合并下载。

<Callout type="info">
如果下载按钮提示"找到多个媒体资源"，说明页面上有多条流无法自动选择，去资源列表手动挑。
</Callout>

## 不同视频格式的处理

| 格式 | 下载方式 |
|---|---|
| HLS / DASH 流（.m3u8 / .mpd） | 桌面端解析分片后下载 |
| 视频+音频分轨 | 合并下载（视频和音频分别下载后自动合并） |
| 普通 MP4 | 直接下载 |

<Callout type="warn">
分轨视频需要视频轨和音频轨都被捕获才能合并。如果点击按钮后提示等待，继续播放几秒后重试。
</Callout>

## 站点差异

| 站点 | 行为 |
|---|---|
| YouTube | 交给桌面端处理（支持画质选择和字幕） |
| Bilibili | 交给桌面端处理（支持画质和多 P） |
| 抖音 / Instagram / X | 扩展自动识别视频和音频轨，合并下载 |
| 其他 | 通用策略：优先流 → 分轨合并 → 单文件 |

## 抓不到的情况

- **DRM 加密视频**（优酷、腾讯视频、爱奇艺等）— 能看到请求但下载后无法播放
- **需要登录的内容** — 用下载按钮（自动携带登录状态），不要从资源列表手动复制链接

详细站点说明见[站点说明](../../reference/site-notes)。
