---
title: Cat Catch Advanced Features
description: Media capture toggles in the extension's Advanced panel.
---

Click extension icon → Advanced. These toggles are powered by [Cat Catch](https://github.com/nichuanfang/cat-catch) integration. Each toggle applies only to the current tab.

| Toggle | Description |
|---|---|
| Recorder | Record playing video/audio |
| WebRTC Capture | Capture video calls and P2P streams |
| Screen Capture | Record tab or entire screen |
| Deep Search | Aggressively scan for hidden media |
| Cache Capture | Extract media from browser cache |
| Mobile UA | Spoof User-Agent as mobile device |
