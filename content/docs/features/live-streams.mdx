---
title: Recording Live Streams
description: Record HLS/DASH live streams.
---

## Start Recording

Paste the live stream's .m3u8 or .mpd link. GD automatically recognizes it as a live stream.

If multiple qualities are available, resolutions can be selected in the confirmation window. You can also set a recording duration limit (leave empty = unlimited).

## During Recording

The task card shows the recorded duration and speed.

<Callout type="warn">
Live stream recording does not support pausing. Stopping ends the recording; it cannot be resumed.
</Callout>

## Stop Recording

Recording ends in the following cases:

- Clicking the stop button
- Reaching the set duration limit
- The live stream itself ends

After stopping, the recorded content is automatically merged into a complete file.

## Encrypted Live Streams

If the live stream is encrypted, GD decrypts it automatically, no extra steps needed.

**Settings → M3U8 Download → MP4 Real-time Decryption** is enabled by default.

## Runtime Requirements

The recording feature requires N_m3u8DL-RE and ffmpeg. Install them in **Settings** before first use. The Android version has them built in.

## Limitations

- The output format is `.ts`. If MP4 is needed, convert manually.
- Network interruptions exceeding a certain duration will cause missing segments in the recording.
