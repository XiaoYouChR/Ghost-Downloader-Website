---
title: 编辑任务
description: 修改下载中或等待中的任务参数。
---

**右键任务 → 编辑任务参数**（任务未完成时可用）。

## 可修改项

| 项目 | 说明 |
|---|---|
| URL | 修改后自动重新解析。如果内容一致则保留进度，不一致会提示重下 |
| 文件名 | 直接改 |
| 下载目录 | 直接改 |
| 线程数 | 增减立即生效 |
| 代理 | 覆盖全局代理设置 |
| 客户端指纹 | 切换浏览器模拟身份，详见 [TLS 指纹](./tls-fingerprint) |
| 请求头 | 表格视图逐行编辑，或文本视图粘贴（支持粘贴 cURL 命令） |

<Callout type="warn">
开启客户端指纹模拟时，手动设置的 User-Agent 不会生效。需要完全自定义请求头时，把指纹设为"不模拟"。
</Callout>

## 请求头预设

常用的请求头组合可以存为预设：**设置 → 请求头预设 → 添加**。新建任务时自动以预设为起点。

## 文件选择

种子、FTP 目录等多文件任务可以随时改勾选，任何状态都行。

- 取消勾选不删除已下载数据，重新勾选从断点继续
- 已完成的任务勾选新文件后自动恢复下载
