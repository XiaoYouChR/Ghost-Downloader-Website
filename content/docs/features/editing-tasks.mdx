---
title: Edit Task
description: Modify options for downloading or waiting tasks.
---

**Right-click task → Edit task options** (available when the task is not complete).

## Editable options

| Item | Description |
|---|---|
| URL | Automatically re-parsed after modification. Progress is retained if the content matches, otherwise prompts to re-download. |
| Filename | Change directly. |
| Download directory | Change directly. |
| Subworkers | Increase or decrease takes effect immediately. |
| Proxy | Overrides global proxy settings. |
| Client fingerprint | Switches browser emulated identity. See [TLS fingerprint](./tls-fingerprint). |
| Request headers | Edit row by row in table view, or paste in text view (pasting cURL commands is supported). |

<Callout type="warn">
When client fingerprint emulation is enabled, a manually set User-Agent will not take effect. To fully customize request headers, set the fingerprint to "No emulation".
</Callout>

## Request header presets

Common request header combinations can be saved as presets: **Settings → Request header presets → Add**. New tasks automatically start from the preset.

## File selection

Multi-file tasks such as torrents and FTP directories can have their selections changed at any time, in any state.

- Unchecking does not delete downloaded data; re-selecting resumes from the breakpoint.
- A completed task automatically revives after selecting new files.
