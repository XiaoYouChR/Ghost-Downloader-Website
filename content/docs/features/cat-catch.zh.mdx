点击扩展图标 → 高级。这里集成了 [猫抓](https://github.com/nichuanfang/cat-catch) 的媒体捕获能力，每个开关只对当前标签页生效。

<TypeTable type={{
  "录制器": { type: "开关", description: "录制页面上正在播放的视频/音频" },
  "WebRTC 捕获": { type: "开关", description: "捕获视频通话、P2P 直播的媒体流" },
  "屏幕捕获": { type: "开关", description: "录制整个标签页或屏幕画面" },
  "深度搜索": { type: "开关", description: "更积极地搜索页面中隐藏的媒体资源" },
  "缓存捕获": { type: "开关", description: "从浏览器缓存中提取已播放过的媒体" },
  "移动端 UA": { type: "开关", description: "伪装为手机访问，部分站点会返回更容易下载的格式" },
}} />

<Callout type="info">
开启移动端 UA 后刷新页面才生效。
</Callout>

## 什么时候用

| 遇到的情况 | 开哪个 |
|---|---|
| 页面上能看到视频但嗅探列表为空 | 录制器 或 深度搜索 |
| 视频通话画面想录下来 | WebRTC 捕获 |
| 网页游戏/Canvas 动画想录制 | 屏幕捕获 |
| 刚才播放过的视频现在链接失效了 | 缓存捕获 |
| 桌面版加密但手机版不加密的站点 | 移动端 UA |
