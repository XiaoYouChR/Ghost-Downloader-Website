---
title: Download Files
description: HTTP and FTP file downloads.
---

## HTTP

Paste a link or capture it from the browser. GD automatically downloads with multiple threads, and automatically increases threads when speed is insufficient.

Supports resume: after pausing, you can continue without starting over.

<Callout type="info">
The number of threads can be adjusted when creating a new task, or modified during download via **Right-click → Edit**.
</Callout>

---

## FTP

Paste an `ftp://` or `ftps://` link. If the link points to a directory, a file tree is listed for selection.

Like HTTP, it supports multiple threads and resume. Proxy supports only SOCKS4/SOCKS5.
