description: HTTP and FTP file downloads.

## HTTP

Paste a link or let the extension intercept. GD downloads with multiple threads and automatically increases speed when bandwidth allows.

Supports resume — pause and continue without restarting.

## FTP

Paste `ftp://` or `ftps://` links. Directory links show a file tree for selection. Proxy: SOCKS4/SOCKS5 only.
