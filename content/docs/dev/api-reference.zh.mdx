## FeaturePack

## FileType / UriScheme

```python
@dataclass(frozen=True)
class FileType:
    extensions: tuple[str, ...]  # (".torrent",)
    displayName: str             # "BitTorrent 种子文件"
    mimeType: str                # "application/x-bittorrent"
    icon: str                    # 图标资源名

@dataclass(frozen=True)
class UriScheme:
    scheme: str       # "magnet"
    displayName: str  # "Magnet 链接"
```
