## Bilibili

登录后可下载更高画质。**设置 → Bilibili 下载 → 账号登录**，支持扫码登录和手动导入 Cookie。

| 画质 | 要求 |
|------|------|
| 480P 及以下 | 无需登录 |
| 720P / 1080P | 需登录 |
| 1080P+ / 4K / HDR / 杜比 | 需大会员 |

多 P 视频在确认窗口中选择要下载的分 P。字幕和封面自动获取，在确认窗口中勾选。

画质不可用时的替代策略可在 **设置 → Bilibili 下载** 中配置。

## YouTube

推荐使用扩展的下载按钮（自动携带登录 Cookie）。直接粘贴链接时，如果遇到需要登录的视频，GD 会尝试使用已保存的 Cookie。

| 问题 | 解决 |
|------|------|
| 会员/年龄限制视频 | 用下载按钮（自动带 Cookie） |
| 验证码 / 频繁 403 | 换 IP 或代理，等一段时间 |
| 画质不全 | 确认是否登录了有会员的账号 |

播放列表：粘贴播放列表链接后选择要下载的视频。

需要 yt-dlp 运行时，首次使用时在设置中安装。

## GitHub Releases

直连 GitHub 不通时，开启 **设置 → GitHub 加速**。GD 内置多个代理站（gh-proxy.com、ghfast.top 等），自动测速选择最快的。也可填入自定义代理站。

代理站不可用时自动回退直连。

## HuggingFace

粘贴模型仓库链接后自动列出文件，勾选需要的下载。

**设置 → HuggingFace** 可配置：
- 镜像站（默认 hf-mirror.com）
- Access Token（下载需要授权的模型如 Llama、Mistral 时填入）

## 抖音

扩展下载按钮直接支持。高清视频会自动合并视频轨和音频轨。

## X (Twitter)

扩展下载按钮直接支持。视频以 HLS 流方式下载。

## Instagram / Facebook

扩展下载按钮直接支持。视频和音频分开下载后自动合并。
