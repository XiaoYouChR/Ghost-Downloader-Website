## Bilibili

After logging in, you can download higher quality. **Settings → Bilibili Download → Account Login** supports QR code login and manual Cookie import.

| Quality | Requirement |
|------|------|
| 480P and below | No login required |
| 720P / 1080P | Login required |
| 1080P+ / 4K / HDR / Dolby | VIP membership required |

For multi-part videos, select the parts to download in the confirmation window. Subtitles and covers are fetched automatically; check them in the confirmation window.

The fallback strategy when a quality is unavailable can be configured in **Settings → Bilibili Download**.

## YouTube

It is recommended to use the extension's download button (automatically carries login cookies). When pasting a link directly, if a video requires login, GD will try to use saved cookies.

| Issue | Solution |
|------|------|
| Member-only / age-restricted videos | Use the download button (automatically carries cookies) |
| Captcha / frequent 403 | Change IP or proxy, wait a while |
| Incomplete quality options | Confirm you are logged in with an account that has membership |

Playlists: paste a playlist link, then select the videos to download.

yt-dlp runtime is required. On first use, install it in Settings.

## GitHub Releases

When a direct connection to GitHub is not available, enable **Settings → GitHub Accelerator**. GD includes multiple proxy sites (gh-proxy.com, ghfast.top, etc.) and automatically tests speeds to choose the fastest. You can also enter a custom proxy site.

When no proxy site is available, it automatically falls back to a direct connection.

## HuggingFace

After pasting a model repository link, files are listed automatically. Check the ones you need to download.

**Settings → HuggingFace** lets you configure:
- Mirror site (default hf-mirror.com)
- Access Token (fill in when downloading models that require authorization, such as Llama, Mistral)

## Douyin

The extension download button supports it directly. HD videos automatically merge video and audio tracks.

## X (Twitter)

The extension download button supports it directly. Videos are downloaded as HLS streams.

## Instagram / Facebook

The extension download button supports it directly. Video and audio are downloaded separately and then merged automatically.
