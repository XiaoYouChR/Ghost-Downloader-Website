---
title: 扩展连不上
description: 浏览器扩展无法连接桌面端的排查步骤。
---

连接断开时扩展会自动重试。如果持续连不上，按以下步骤排查。

<Steps>
<Step>
### 确认桌面端在运行

扩展只能连接正在运行的 Ghost Downloader。检查系统托盘是否有 GD 图标。

</Step>
<Step>
### 检查端口

默认端口 `14370`。如果被其他程序占用会连不上。

**桌面端设置 → 浏览器扩展** 中修改端口号，然后在扩展设置中填入相同端口。两边必须一致。

</Step>
<Step>
### Token 失效

扩展提示未授权 → Token 过期或不匹配。

**桌面端设置 → 浏览器扩展** → 重新生成 Token → 复制粘贴到扩展设置。

</Step>
<Step>
### 防火墙拦截

部分防火墙会阻止本机网络通信。将 Ghost Downloader 加入白名单，或临时关闭防火墙测试。

</Step>
<Step>
### 浏览器不兼容

Vivaldi 等浏览器可能有兼容问题。换 Chrome 或 Edge 测试，确认是否是浏览器本身的问题。

</Step>
<Step>
### 重新配对

以上都不行，彻底重置：

1. 扩展设置中清除 Token
2. **桌面端设置 → 浏览器扩展** → 重新生成 Token
3. 扩展中点配对按钮，重走配对流程

</Step>
</Steps>

<Callout type="info">
扩展在桌面端未连接时拦截的下载不会丢失，重新连接后自动发送。
</Callout>
