---
title: Corrupted Download
description: The file cannot be opened or its size is abnormal.
---

Downloaded files that cannot be opened, have abnormal sizes, or fail to extract are usually caused by the server's incomplete support for segmented downloads.

**Fix:** Set thread count to 1 and re-download (**Right-click the task → Re-download**).

If the problem persists, submit an [Issue](https://github.com/XiaoYouChR/Ghost-Downloader-3/issues) with logs attached.
