---
title: Corrupted Downloads
description: Files won't open or have wrong size.
---

Usually caused by servers not properly supporting multi-threaded downloads.

**Fix:** Set thread count to 1 and redownload (**right-click task → Redownload**).

If the problem persists, file an [Issue](https://github.com/XiaoYouChR/Ghost-Downloader-3/issues).
