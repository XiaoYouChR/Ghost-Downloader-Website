Below are other common issues.

## Browser Extension

<Accordions>
<Accordion title="Protocol version mismatch">
The desktop and extension versions are not from the same generation. Update both to the latest version. If the store version of the extension is not updated, use **Settings → Browser Extension → One-click Install**.
</Accordion>

<Accordion title="Invalid pairing token">
In the extension, click **Auto Pair**, and when the desktop shows a request, click Allow.
</Accordion>

<Accordion title="An extra canceled entry appears in Firefox's download manager">
Normal. Firefox's interception mechanism creates a download entry before canceling it, so the Firefox download manager shows a "Canceled" record. The file is not actually downloaded twice. Ignore it.
</Accordion>

<Accordion title="Cannot take over browser downloads on Android">
Most Android browsers do not support extensions. Copy the link and paste it in GD, or use the system share menu.
</Accordion>
</Accordions>

## Download

<Accordions>
<Accordion title="Download stalls at the last few KB, speed drops to zero">
Pause and resume. When it recurs, set **Settings → General Download Settings → Minimum Reallocation Size** to 2048 KB or higher.
</Accordion>

<Accordion title="Download fails immediately with a server error">
**Right-click the task → Edit**, and check whether the link has expired or requires cookies. For 403 / Cloudflare blocks, try a different client profile.
</Accordion>

<Accordion title="SSL handshake failed">
Make sure **Settings → General Download Settings → Verify SSL Certificate** is off (off by default). If that does not work, switch the client profile.
</Accordion>
</Accordions>

## Installation and Startup

<Accordions>
<Accordion title="Linux (Arch/KDE): clicking does nothing">
The Qt bundled with `ghost-downloader-bin` conflicts with the system. Switch to:

```bash
paru -S ghost-downloader-git
```
</Accordion>

<Accordion title="Runtime (yt-dlp / FFmpeg / eD2k) installation failed">
Downloads come from GitHub. If your network cannot reach it, enable a proxy and retry.
</Accordion>
</Accordions>
