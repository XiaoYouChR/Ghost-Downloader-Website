---
title: Update Failed
description: What to do when auto-update doesn't work.
---

GD checks GitHub Releases on startup and downloads updates as a regular task.

1. **Network** — update check needs GitHub access. Configure a proxy if needed.
2. **Download fails** — same as any download. Check proxy and retry.
3. **Manual update** — download the latest installer from [GitHub Releases](https://github.com/XiaoYouChR/Ghost-Downloader-3/releases/latest) and install over the existing version.
