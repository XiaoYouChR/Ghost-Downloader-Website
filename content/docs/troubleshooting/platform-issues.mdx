## "App Is Damaged and Cannot Be Opened"

macOS Gatekeeper blocks apps not notarized by Apple.

**Fix:**

1. Open the "Fix Damaged Software" script in the DMG and run it.
2. If the script does not exist, run in Terminal:

```bash
xattr -cr /Applications/Ghost\ Downloader.app
```

Then reopen the app.

<Tab value="Windows">

## Smart App Control Blocks Startup

Windows 11's Smart App Control may prevent GD from starting.

**Workaround:**

- Use the portable version (`.zip`, extract and run)
- Or turn off Smart App Control in **Windows Security → App and browser control**

## Defender False Positive

Windows Defender occasionally flags Nuitka-compiled binaries as a threat.

**Workaround:**

Add the GD installation directory to Windows Security → Virus and threat protection → Exclusions.

</Tab>
<Tab value="Linux">

## AppImage Does Not Run

After download, add execute permission:

```bash
chmod +x Ghost-Downloader-*.AppImage
```

## Cannot Start (Missing Dependencies)

Some distributions need `libfuse2` (AppImage runtime dependency):

```bash
sudo apt install libfuse2
```
