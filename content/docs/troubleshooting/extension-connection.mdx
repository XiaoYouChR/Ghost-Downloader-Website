---
title: Extension Cannot Connect
description: Troubleshooting steps for when the browser extension cannot connect to the desktop app.
---

When the connection is lost, the extension automatically retries. If it still cannot connect, follow these steps to troubleshoot.

<Steps>
<Step>
### Confirm the desktop app is running

The extension can only connect to a running Ghost Downloader. Check the system tray for the GD icon.

</Step>
<Step>
### Check the port

The default port is `14370`. If it is occupied by another program, the connection will fail.

Change the port in **Desktop Settings → Browser Extension**, then enter the same port in the extension settings. Both sides must match.

</Step>
<Step>
### Token expired

The extension prompts unauthorized → Token expired or mismatched.

**Desktop Settings → Browser Extension** → Regenerate Token → Copy and paste into extension settings.

</Step>
<Step>
### Firewall blocking

Some firewalls block local network communication. Add Ghost Downloader to the whitelist, or temporarily disable the firewall to test.

</Step>
<Step>
### Browser incompatibility

Browsers such as Vivaldi may have compatibility issues. Try Chrome or Edge to confirm whether the problem is caused by the browser itself.

</Step>
<Step>
### Re-pair

If none of the above works, reset completely:

1. Clear the Token in the extension settings
2. **Desktop Settings → Browser Extension** → Regenerate Token
3. Click the pair button in the extension and go through the pairing flow again

</Step>
</Steps>

<Callout type="info">
Downloads intercepted by the extension while the desktop app is not connected will not be lost. They are sent automatically after reconnecting.
</Callout>
