## 安装扩展

| 方式 | 适用浏览器 | 特点 |
|---|---|---|
| 一键安装 | Chrome、Brave 等 Chromium 系 | 随桌面端更新自动升级 |
| 商店安装 | Chrome、Edge、Firefox | 更新取决于商店审核周期 |
| 导出 CRX | Chromium 系 | 手动导出安装，适用于受限环境 |

三种方式都在 **设置 → 浏览器扩展** 中找到入口。

## 配对

安装后需要配对，扩展才能向桌面端发送下载请求。

<Steps>
<Step>
### 自动配对

打开扩展面板 → 设置 → 点击自动配对。桌面端弹出配对请求，点击允许。完成。
</Step>
<Step>
### 手动配对（备选）

如果自动配对不弹窗：**桌面端设置 → 浏览器扩展** → 复制配对令牌 → 粘贴到扩展设置的令牌输入框。
</Step>
</Steps>

配对成功后扩展面板顶部显示已连接状态。

## 重新生成令牌

**设置 → 浏览器扩展 → 配对令牌** 旁的刷新按钮。新令牌立即生效，已连接的扩展会断开，需要重新配对。

用于：令牌泄露、换浏览器后忘记旧令牌。

<Callout type="info">
连不上？见[扩展连不上](../../troubleshooting/extension-connection)。
</Callout>
