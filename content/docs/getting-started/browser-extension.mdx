## Install the Extension

| Method | Compatible Browsers | Notes |
|---|---|---|
| One-click install | Chrome, Brave, and other Chromium-based browsers | Auto-updates with the desktop app |
| Store install | Chrome, Edge, Firefox | Updates depend on the store review cycle |
| Export CRX | Chromium-based browsers | Manually export and install, for restricted environments |

All three methods are available under **Settings → Browser Extension**.

## Pairing

After installation, pairing is required before the extension can send download requests to the desktop app.

<Steps>
<Step>
### Automatic Pairing

Open the extension panel → Settings → click Automatic Pairing. The desktop app shows a pairing request; click Allow. Done.
</Step>
<Step>
### Manual Pairing (Alternative)

If Automatic Pairing does not show a prompt: **Desktop app Settings → Browser Extension** → copy the pairing token → paste it into the token input in the extension settings.
</Step>
</Steps>

After successful pairing, the top of the extension panel shows the Connected status.

## Regenerate the Token

The refresh button next to **Settings → Browser Extension → Pairing Token**. The new token takes effect immediately; connected extensions are disconnected and must be paired again.

Use this when the token is leaked or you forget the old token after switching browsers.
