## 系统要求

| 平台 | 最低版本 | 架构 |
|---|---|---|
| Windows | 10+ | x86_64, arm64 |
| macOS | 13.0+ | x86_64, arm64 |
| Linux | glibc 2.35+ | x86_64, arm64 |
| Android | 10+ | arm64 |

<Callout type="warn">
不支持 Windows 7 和不支持 AVX 指令集的 CPU（2011 年以前的处理器）。
</Callout>

## 下载和安装

从 [GitHub Releases](https://github.com/XiaoYouChR/Ghost-Downloader-3/releases/latest) 下载对应平台的安装包。

<Tabs groupId="os" items={["Windows", "macOS", "Linux", "Android"]}>

<Tab value="Windows">

| 文件 | 说明 |
|---|---|
| `*-Setup.exe` | 安装包，写入 Program Files，创建快捷方式 |
| `*.zip` | 便携版，解压即用，不改注册表 |

注意选择与系统架构匹配的版本（x86_64 或 arm64）。

遇到启动问题见[平台特定问题](../../troubleshooting/platform-issues)。

</Tab>

<Tab value="macOS">

下载 `.dmg`，拖入 Applications。

首次打开会被 Gatekeeper 阻止。运行 DMG 内的"修复软件损坏"脚本即可解决。详见[平台特定问题](../../troubleshooting/platform-issues)。

</Tab>

<Tab value="Linux">

| 格式 | 说明 |
|---|---|
| `.deb` | 安装到 `/opt`，注册桌面入口 |
| `.AppImage` | 单文件，`chmod +x` 后直接运行 |
| `.tar.xz` | 解压后运行 `Ghost-Downloader-3.bin` |

Arch Linux 可用 AUR：[`ghost-downloader-bin`](https://aur.archlinux.org/packages/ghost-downloader-bin)

</Tab>

<Tab value="Android">

下载 `.apk` 安装。仅 arm64 架构，不支持模拟器。

</Tab>

</Tabs>

## 安装版 vs 便携版（Windows）

安装版数据存储在系统用户目录。便携版数据跟随程序文件夹。

在 `.exe` 同级目录创建空的 `GhostDownloader` 文件夹即可激活便携模式。运行中可在 **设置 → 应用 → 数据存储模式** 切换。
