## System Requirements

| Platform | Minimum Version | Architecture |
|---|---|---|
| Windows | 10+ | x86_64, arm64 |
| macOS | 13.0+ | x86_64, arm64 |
| Linux | glibc 2.35+ | x86_64, arm64 |
| Android | 10+ | arm64 |

<Callout type="warn">
Windows 7 and CPUs without AVX instruction set support (processors from before 2011) are not supported.
</Callout>

## Download and Install

Download the installer for your platform from [GitHub Releases](https://github.com/XiaoYouChR/Ghost-Downloader-3/releases/latest).

<Tabs groupId="os" items={["Windows", "macOS", "Linux", "Android"]}>

<Tab value="Windows">

| File | Description |
|---|---|
| `*-Setup.exe` | Installer, writes to Program Files, creates shortcut |
| `*.zip` | Portable version, extract and run, no registry changes |

Make sure to choose the version matching your system architecture (x86_64 or arm64).

For startup issues, see [Platform-Specific Issues](../../troubleshooting/platform-issues).

</Tab>

<Tab value="macOS">

Download the `.dmg` and drag it into Applications.

The first launch is blocked by Gatekeeper. Running the "Repair Damaged Software" script inside the DMG resolves it. See [Platform-Specific Issues](../../troubleshooting/platform-issues) for details.

</Tab>

<Tab value="Linux">

| Format | Description |
|---|---|
| `.deb` | Installs to `/opt`, registers desktop entry |
| `.AppImage` | Single file, run directly after `chmod +x` |
| `.tar.xz` | Extract and run `Ghost-Downloader-3.bin` |

Arch Linux users can use the AUR: [`ghost-downloader-bin`](https://aur.archlinux.org/packages/ghost-downloader-bin)

</Tab>

<Tab value="Android">

Download the `.apk` and install it. arm64 architecture only, emulators are not supported.

</Tab>

</Tabs>

## Installed vs Portable (Windows)

The installed version stores data in the system user directory. The portable version keeps data in the program folder.

Create an empty `GhostDownloader` folder next to the `.exe` to activate portable mode. While running, you can switch in **Settings → App → Data Storage Mode**.
