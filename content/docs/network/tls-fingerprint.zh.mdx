## 为什么其他下载器会被拦

部分网站会检查下载工具的网络特征。普通下载器的特征和真实浏览器差异明显，直接被拒绝（403）或弹验证页面。

GD 能模拟真实浏览器的网络特征，让服务器认为这是正常的浏览器请求。

## 全局设置

**设置 → 综合下载设置 → 模拟身份**

| 选项 | 效果 |
|---|---|
| 自动 | 默认。从扩展来的任务自动匹配来源浏览器，手动添加的用 Chrome 最新版 |
| 不模拟 | 关闭指纹模拟。仅在需要完全自定义请求头时使用 |
| 指定浏览器 | 锁定为 Chrome / Edge / Firefox / Safari 等（可选具体版本） |

## 按域名切换

遇到特定站点需要不同指纹时，创建身份预设：

**设置 → 身份预设 → 添加**

填入匹配域名（支持 `*.example.com` 通配）、选择指纹，保存。命中预设的下载自动使用预设指纹。

预设按列表顺序匹配，拖动调整优先级。

## 什么时候需要动

日常保持"自动"即可。以下情况手动切换：

- 下载被 403 → **右键任务 → 编辑** → 换个浏览器指纹
- 同一站点反复被拦 → 为该域名建身份预设
- 速度异常慢 → 尝试换指纹 + 降低线程数
