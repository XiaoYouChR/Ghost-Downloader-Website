安卓端和桌面端编译自同一套代码，核心下载功能一致。本页只写不同的部分。

## 不支持的功能

- BitTorrent / Magnet
- eD2k

## 安装

从 [GitHub Releases](https://github.com/XiaoYouChR/Ghost-Downloader-3/releases) 下载 `.apk` 安装。仅支持 ARM64 设备。

## 权限

首次启动时需要授权：

| 权限 | 用途 |
|---|---|
| 存储权限 | 下载文件到公共目录（如 Download 文件夹） |
| 通知权限 | 下载完成提醒 + 后台下载状态显示 |
| 忽略电池优化 | 防止系统在后台杀死下载进程 |

<Callout type="warn">
国产 ROM（MIUI、ColorOS、OriginOS 等）需要额外将 GD 加入"后台不限制"白名单，否则息屏后下载可能中断。路径通常在系统设置 → 应用管理 → GD → 省电策略。
</Callout>

## 后台下载

有任务在跑时，状态栏会显示常驻通知。按返回键不会退出，而是切到后台继续下载。

## 配对浏览器扩展

和桌面端方式相同。安卓端也能接收扩展推送的下载任务。

## 接收分享

从其他应用（浏览器、文件管理器）分享链接或文件到 GD：

- 分享文本 → 自动提取链接并创建任务
- 分享 .torrent / .m3u8 文件 → 直接创建任务

## 已知限制

- 无法注册为系统默认下载器（Android 系统限制）
- 强制竖屏，暂未适配平板横屏
